\caption{Comparison of classification heads for RQ3. Both variants use the first-token representation from a RoBERTa encoder. The baseline maps this representation directly to six label scores. The label-dependency variant projects it into six label-specific vectors, performs one graph message-passing step using a fixed adjacency matrix estimated from training-label co-occurrence, and scores the updated vectors. The adjacency has a zero diagonal, while a separate self-transformation retains each label's own information. The variants are trained separately using binary cross-entropy and evaluated using five-fold Macro ROC-AUC; the shared encoder illustration denotes the same backbone architecture, not shared fitted weights. Held-out labels are not used to construct the graph.}
\label{fig:rq3-label-dependency}
