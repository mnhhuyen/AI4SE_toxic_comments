\caption{Modeling pipelines for RQ2 using pretrained FastText embeddings. The pooled-feature branch concatenates max pooling and supervised attention over token embeddings, then fits logistic regression (LR) or LightGBM on the resulting features. The recurrent branch applies max pooling and supervised attention to encoder hidden states, with attention and the classification head trained jointly with the encoder. DPCNN uses a convolutional hierarchy. Each pipeline produces six label-specific scores and is evaluated separately; the branches do not form an ensemble. Supervised pooling is fitted using training data only within each fold.}
